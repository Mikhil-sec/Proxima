## Stack

- Jetpack Compose (BOM 2026.09.00) + Material 3
- Kotlin 2.4.21, AGP 9.5.1
- minSdk 26, targetSdk 36. **WAIVED** (skill asks for minSdk ≥ 34): the team's demo phones run Android 13/14 and
  the contract modules are minSdk 26. Variable fonts need API 26+, which we have. Predictive back works on 34+ devices.
- Mode: bootstrap (replaced the previous custom theme)

## Aesthetic Anchors

- **Primary:** Material You (Android Expressive) — whole recipe: colour, type, shapes, motion.
- **Type accent:** none · **Motion accent:** none

See `~/.claude/skills/ui-android/anchors.md` § 7 for the recipe. Every choice must trace to it.

## Active Ban Patterns

1. Generic gradient slop — no gradient brushes at all.
2. Lorem ipsum & filler copy — real, specific copy only (see copy rules below).
3. Arbitrary values — no `dp` / `sp` / `Color(0x…)` / inline `RoundedCornerShape(n)` outside `ui/theme/`.
8. Decorative motion — no `rememberInfiniteTransition`, no looping glows / breathing / sweeps. Motion only answers
   a state change (arming the SOS, a packet hop arriving, a sheet opening).

See `~/.claude/skills/ui-android/ban-patterns.md` for detection rules. Enforced by `./gradlew :app:designCheck`.

## Tokens — single source of truth

| Token | File |
|---|---|
| ColorScheme (light + dark) + semantic roles (critical / urgent / caution / safe) | `app/src/main/java/mu/proxima/app/ui/theme/Color.kt` |
| Typography (Roboto Flex variable, 7 sizes) | `app/src/main/java/mu/proxima/app/ui/theme/Type.kt` |
| Shapes (4 / 8 / 12 / 16 / 28) | `app/src/main/java/mu/proxima/app/ui/theme/Shape.kt` |
| Spacing + component sizes | `app/src/main/java/mu/proxima/app/ui/theme/Spacing.kt` (`MaterialTheme.spacing`, `MaterialTheme.sizes`) |
| Motion (M3 durations + easings, mirrored because `MotionTokens` is internal) | `app/src/main/java/mu/proxima/app/ui/theme/Motion.kt` |
| Theme wrapper | `app/src/main/java/mu/proxima/app/ui/theme/Theme.kt` (`ProximaTheme`, `MaterialTheme.semantic`) |

**NEVER use values outside these tokens.** No `Modifier.padding(13.dp)`, no inline `Color(0xFF3A4F6B)`, no inline
`TextStyle(fontSize = 13.sp)`, no one-off `RoundedCornerShape(7.dp)`.

## Semantic colour use (Proxima-specific)

| Role | Means | Never |
|---|---|---|
| `semantic.critical` | SOS, CRITICAL incidents | decoration, brand |
| `semantic.urgent` | HIGH severity | |
| `semantic.caution` | MEDIUM severity, unverified relay, simulation badge | |
| `semantic.safe` | verified, connected, found | buttons, brand |
| `colorScheme.primary` (teal) | brand, primary actions, links | severity |

Colour is never the only signal: severity also carries a word, verification also carries an icon.

## Card variant (project-wide choice)

**OutlinedCard** for content groupings (tickets, sheets' sub-sections). Lists are `ListItem`s, not cards.

## Press feedback (project-wide choice)

**ripple** (Material default). The SOS ring is the one custom gesture (0.6 s hold to arm) and shows an arming arc.

## Density mode

**balanced** on phones · **dense** on the tablet Command Center.

## Dark theme

**required** — follows the system setting; both schemes pass WCAG AA.

## Dynamic color (Material You wallpaper-derived)

**off** — fixed lagoon-teal seed so every demo phone and the tablet look the same.

## Material Symbols icon family

**Rounded** (`materialsymbolsrounded`, weight 400, fill 0), imported as vector drawables under `res/drawable/ic_*.xml`
from google/material-design-icons (Apache 2.0). Selection convention: none. No hand-drawn Canvas icons.

## Verification command

Before claiming any UI work done, run:

```bash
./gradlew :app:designCheck :app:lintDebug
```

`designCheck` must report 0 violations. detekt itself is **WAIVED** (detekt 1.23 does not support Kotlin 2.4);
`designCheck` implements the skill's `detektDesign` regex rules as a plain Gradle task wired into `check`.

## Component anatomy

See `~/.claude/skills/ui-android/component-anatomy.md`. Touch targets ≥ 48dp, edge-to-edge always on, predictive back
honoured. Proxima rules on top: civilian screens have one primary action; SOS ≥ 200 dp; no `AlertDialog` for
emergency flows (bottom sheets instead).

## Copy voice

Material You voice: friendly, second person, practical. Sentence case on every label. Plain words a panicking parent
understands; the same verb through a flow ("Send alert" → "Alert sent"). No names, photos or personal details in
example text (privacy rule). See `~/.claude/skills/ui-android/copy-voice.md`.

## Adding new tokens

If you need a value that doesn't exist in the theme files: STOP. Ask the UI lane (Mikhil) to extend the theme.
NEVER add arbitrary values inline.
